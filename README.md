# Závěrečný workshop

Závěrečný workshop kurzu PyLadies Praha (běh **podzim 2026**).
Všechno, co ses v kurzu naučila, použiješ dohromady na jednom větším úkolu.

Výukové materiály k jednotlivým lekcím najdeš v repozitáři
[materialy](https://github.com/pyladiesprague/materialy).

## Jak si materiály stáhnout

Nahoře klikni na zelené tlačítko **Code** → **Download ZIP**. Stažený archiv
rozbal a složku otevři ve VS Code (**File → Open Folder**).

Obsah sem přidávají koučové. Pokud chceš navrhnout úpravu, vytvoř si fork
a pošli pull request.
